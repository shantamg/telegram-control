# Screenshot checklist

Screenshots are intentionally deferred until a sanitized demonstration bot and
project group are available. Do not capture the maintainer's live installation.

Useful future images:

1. BotFather bot creation with the token area fully absent.
2. The `/newgroup` card in the private bot chat.
3. Telegram group settings with Topics enabled.
4. The separate **View as Topics** menu choice.
5. The `/bind` confirmation with a fabricated local path.
6. A topic list containing several clearly fictional agent conversations.
7. An individual topic's standard status card and first completed turn.
8. The `/agent` controls and `/help` home.

Before committing an image, verify that it contains no real:

- person name, username, phone number, avatar, or notification preview;
- bot token or private bot username;
- group invitation link or Telegram numeric identifier;
- filesystem username or path;
- repository, client, or project name;
- provider account, session identifier, or usage data.

Use consistent dimensions, add descriptive alt text where embedded, and update
the affected guide when a Telegram interface change makes a screenshot stale.
